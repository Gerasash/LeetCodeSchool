# PRD — Образовательная платформа для изучения программирования

## Обзор продукта

Веб-платформа для обучения программированию с автоматической проверкой кода и ИИ-ревью,
ориентированная на школьников (7–11 класс) и студентов вузов (1–4 курс).

## Целевая аудитория

| Роль | Описание |
|------|----------|
| **Ученик / студент** | Решает задачи по программированию, видит результаты тестов и получает ИИ-подсказки |
| **Преподаватель** | Управляет группами, видит прогресс и сводку типичных ошибок |

## Ключевые возможности

1. **Иерархия учебных треков**: Класс школы / курс вуза → Тема → Задачи.
2. **Язык MVP — C++** (компиляция и запуск в изолированной песочнице Piston).
3. **Редактор кода в браузере** (Monaco Editor с подсветкой синтаксиса C++).
4. **Автоматическая проверка** по набору тестов (stdin → expected stdout).
5. **Киллер-фича — ИИ-подсветка ошибочной строки** через DeepSeek:
   - 3 уровня подсказок (Сократовский метод — без готового решения на 1–2 уровне).
   - Подсветка конкретных строк прямо в Monaco Editor.
   - Строки нумеруются бэкендом перед отправкой в DeepSeek.
6. **Кабинет преподавателя**: учебные группы, сводка ошибок по задачам.

## Технологический стек

| Слой | Технология |
|------|-----------|
| Frontend | React + Vite + TypeScript + Tailwind CSS + Monaco Editor |
| Backend | Python 3.11+ + FastAPI + Pydantic v2 |
| Песочница C++ | Piston (Docker) |
| ИИ-подсказки | DeepSeek API (OpenAI-совместимый) |
| БД (с Среза 3) | SQLite + SQLAlchemy 2.0 (async) + Alembic |

## Метрики успеха MVP

- Ученик может написать C++ код в браузере и получить мгновенный результат проверки.
- ИИ-подсказки помогают найти ошибку, не выдавая готовое решение.
- Преподаватель видит прогресс группы.
