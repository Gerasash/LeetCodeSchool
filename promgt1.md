
## Промпт №1 для Antigravity (Старт и Срез 1)

Откройте в Antigravity пустую папку проекта, выберите модель **Claude Opus 4.6** (для закладки фундамента лучше сразу взять её) и отправьте этот промпт:

```markdown
Инициализируй проект и реализуй Вертикальный Срез 1 (рабочая проверка C++ кода в браузере, пока без базы данных, авторизации и без DeepSeek).

Что нужно сделать:
1. Создай папку `docs/` и заполни три файла:
   - `docs/PRD.md` — краткое описание платформы (треки по классам школы и курсам вуза, язык MVP — C++, киллер-фича — ИИ-подсветка ошибочной строки через DeepSeek без выдачи готового ответа).
   - `docs/ARCHITECTURE.md` — описание стека, схемы взаимодействия Frontend -> FastAPI -> Piston -> DeepSeek и JSON-контрактов для Среза 1.
   - `docs/TASKS.md` — план из 4 вертикальных срезов:
     * Срез 1: Скелет проверки C++ (Monaco Editor + FastAPI + Piston, 1 захардкоженная задача).
     * Срез 2: Интеграция DeepSeek API (нумерация строк, 3 уровня подсказок, подсветка строк в Monaco Editor).
     * Срез 3: БД SQLite, иерархия «Класс/Курс -> Тема -> Задачи», сохранение прогресса.
     * Срез 4: Кабинет преподавателя, учебные группы и сводка ошибок.

2. Настрой песочницу Piston:
   - Создай `docker-compose.yml` с сервисом `piston` (`ghcr.io/engineer-man/piston`, порт 2000).
   - Учти, что чистый образ Piston не содержит компилятор C++ из коробки: создай простой Python-скрипт `scripts/setup_piston.py`, который проверяет доступность Piston и устанавливает пакет `gcc` через Piston API (`POST /api/v2/packages`).

3. Сделай бэкенд в папке `backend/` (FastAPI):
   - Захардкодь 1 учебную задачу по C++ (например, «Сумма чётных чисел в массиве» для 9 класса) с условием, стартовым шаблоном кода и 3 тест-кейсами (stdin / expected_stdout).
   - Эндпоинт `GET /api/problems/1` — возвращает условие, шаблон кода и видимые примеры тестов.
   - Эндпоинт `POST /api/submit` — принимает `{ "problem_id": 1, "code": "..." }`, отправляет код в Piston на компиляцию и прогон по всем тестам.
   - Если ошибка компиляции — верни статус `compile_error` и текст `stderr`. Если скомпилировалось — верни общий статус (`accepted` или `wrong_answer` / `runtime_error`) и массив результатов по каждому тесту (`passed`, `input`, `expected`, `actual`, `stderr`).
   - Настрой CORS для локального фронтенда.

4. Сделай фронтенд в папке `frontend/` (React + Vite + TypeScript + Tailwind + `@monaco-editor/react`):
   - Двухколоночный интерфейс (как в LeetCode): слева — условие задачи и панель результатов тестов; справа — редактор Monaco с подсветкой синтаксиса C++ и кнопкой «Проверить решение».
   - При нажатии «Проверить решение» показывай состояние загрузки, а затем аккуратно выводи либо ошибку компиляции, либо список тестов (зелёный/красный с ожидаемым и полученным выводом).

В конце дай пошаговые команды для моего терминала (Windows/PowerShell или Linux/Mac), чтобы поднять Docker, установить gcc в Piston, запустить бэкенд и фронтенд.


## Что делать вам прямо сейчас

1. Создайте пустую папку под проект и откройте её в Antigravity.
2. Положите **Мастер-промпт** в правила IDE.
3. Запустите **Промпт №1** на модели **Claude Opus 4.6**.
4. Выполните команды запуска, которые выдаст IDE (убедитесь, что Docker Desktop запущен), и попробуйте отправить правильный и неправильный C++-код на странице.

Если на каком-то шаге вылезет ошибка в терминале — просто кидайте её в Antigravity или сюда. Как только Срез 1 заработает и тесты начнут прогоняться, напишите мне — я дам **Промпт №2** на подключение DeepSeek и подсветку ошибочных строк прямо в редакторе.
